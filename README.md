# Gran Bingo Familiar Solidario · CGPA Colegio Oratorio Don Bosco

Tablero de bingo de 75 números (B·I·N·G·O) para proyectar durante el evento.

**Abrir el bingo:** https://postiaok-dotcom.github.io/bingo-cgpa/

- Marca los números a medida que salen (toque o teclado: número + Enter).
- Muestra el número actual en grande y la trayectoria completa en orden.
- Sorteo de figuras al azar: Línea, Letra X, Letra O, 4 Esquinas, Cartón lleno y más.
- Verificación de cartones, celebración de ¡Bingo!, ventana para proyector.
- Se puede instalar como aplicación y funciona sin internet.

Abrir: `index.html` · Versión para Google Sites: `bingo-google-sites.html`
